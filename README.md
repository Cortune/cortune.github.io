## `> whoami`

```bash
$ cat /dev/cortune
Nome:   Cortune · estúdio multimídia
Foco:   vídeo · áudio · imagens · PDFs
Modo:   PWA instalável · offline · processamento no navegador
Custo:  gratuito · sem anúncios
Idiomas: Português · English · Español
```

O **Cortune** reúne ferramentas para editar vídeos, áudio e imagens direto no navegador. Os arquivos são processados localmente no dispositivo, sem serem enviados a servidores, e o estúdio pode ser instalado para uso offline.

---

## `> ls ./estudios`

| Estúdio | Ferramentas |
| --- | --- |
| 🎬 **Vídeo** | Cortar e juntar clipes, silenciar o vídeo ou todo o áudio, adicionar música de fundo, alterar velocidade, reverter quadros e exportar GIFs ou vídeos verticais 9:16 |
| 🎧 **Áudio** | Extrair WAV de vídeos, silenciar trechos selecionados, gravar pelo microfone, normalizar volume, visualizar forma de onda e ajustar equalizador de 3 bandas |
| 🖼️ **Editor de imagens** | Filtros, histograma RGB, comparação antes/depois, recortes predefinidos, pixelização e censura, remoção de fundo por cor, desenho e aplicação de logotipo |
| 📦 **Lote, HEIC, colagem e PDF** | Comprimir várias fotos, converter HEIC para JPG, gerar favicons ICO em vários tamanhos, criar colagens e montar PDFs com fotos |

## `> cat ./privacidade`

```json
{
  "processamento": "local no navegador",
  "upload_de_arquivos": false,
  "rastreamento": false,
  "uso_offline": true,
  "assinatura_obrigatoria": false,
  "anuncios": false
}
```

- **Arquivos no seu dispositivo:** o Cortune informa que processa os arquivos localmente no navegador, sem enviá-los para servidores ou para a nuvem.

- **Uso offline:** instale o app e use as ferramentas sem depender de conexão com a internet.

- **Sem anúncios ou assinatura obrigatória:** o projeto se apresenta como gratuito e sem anúncios.

- **Permissões do aparelho:** recursos como gravação de voz podem solicitar acesso ao microfone do dispositivo.

## `> ./iniciar`

```bash
1. Acesse   cortune.github.io
2. Escolha  Vídeo, Áudio, Imagem ou ferramentas em lote
3. Importe  selecione o arquivo que deseja editar no dispositivo
4. Edite    processe no navegador e salve o resultado
5. Instale  use "Install App" para adicionar o PWA ao celular ou computador
```
